# Deploy this portfolio

## Netlify
1. Put `resume.pdf` in this folder.
2. Open Netlify and choose **Add new site → Deploy manually**.
3. Drag the entire `Devendra-Portfolio` folder into the deploy area.
4. The site will be live with the portfolio and resume.

## GitHub Pages
1. Create a repository such as `devendra118.github.io`.
2. Upload all files from this folder to the repository root.
3. Enable GitHub Pages from repository Settings → Pages.
4. Select the main branch and root folder.

## Before deployment
- Add your current PDF resume as `resume.pdf`.
- Replace any project/demo URL if the live project URL has changed.
- Test every navigation and project link on mobile.
